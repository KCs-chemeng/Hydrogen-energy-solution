## 이번 환경에서 수행하지 않은 검증

Windows/macOS 실행, EXE 빌드, 실제 Windows GUI 클릭·파일 대화상자·DPI·한국어 글꼴의 시각 검수는 하지 않았습니다. Windows `.bat` 실행 스크립트는 제공했으며 실제 실행 검증은 Linux의 설치·실행 스크립트와 Tk 테스트로 수행했습니다. 배포 대상 PC의 짧은 검수 절차는 README_KO.md에 있습니다. 다른 Python/라이브러리 버전의 동일 난수 결과를 보증하지 않습니다. 사용자 업무의 실제 승인·날짜·모듈 적용성은 자동으로 결정하지 않습니다.
