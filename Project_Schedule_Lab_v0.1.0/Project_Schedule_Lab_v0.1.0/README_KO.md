# 공정표 · Project Schedule Lab v0.1.0

Jira 없이 사용하는 Python 데스크톱 일정관리 초안입니다. 엑셀을 입력/교환 기준으로 두고 확률 일정과 분석 이력을 관리합니다.

## 실행

1. ZIP 전체를 쓰기 가능한 폴더에 압축 해제합니다. ZIP 안에서 직접 실행하지 마세요.
2. Windows용 Python 3.11 이상을 설치합니다. Tcl/Tk 항목을 포함해야 합니다.
3. install.bat을 실행합니다. 처음 한 번 인터넷으로 numpy와 openpyxl을 설치합니다.
4. 설치가 끝나면 start.bat을 실행합니다.
5. 예제 프로젝트에서 시뮬레이션 실행을 누릅니다.

실행파일(EXE) 배포본은 아닙니다. Python 소스와 실행 스크립트 패키지입니다. Python 환경이 이미 있으면 `python -m pip install -r requirements.txt` 후 `python app.py`로도 실행할 수 있습니다. 터미널의 작업 폴더는 이 파일이 있는 위치입니다.

공식 다운로드: https://www.python.org/downloads/windows/

## 빠른 사용

- 기본 창: 1500×900. 상단에서 엑셀 입출력, 공통 템플릿, 설정, 기준선 저장을 선택합니다.
- 확률 로드맵: 작업·모듈별 파랑/초록 막대, 선행 연결선, 프로젝트 완료 범위. P50~P95 슬라이더로 조회 기준을 바꿉니다.
- 파랑 막대: 시작 P50~선택 P. 초록 막대: 완료 P50~선택 P. 얇은선: 시작 P10~완료 선택 P.
- 막대는 주변분포를 요약하므로 전체 막대가 하나의 실행 일정은 아닙니다. 연결선은 P50 위치를 연결합니다.
- 모듈 제목 클릭: 접기/펼치기. 작업행 더블클릭: 상세 편집.
- 완료일 분포: 시뮬레이션의 완료일 빈도와 P50/P80/P90을 표시합니다.
- 작업 편집: 검색, 추가, 복사, 상세 편집, 제외. ID는 신규 생성 시 결정하며 기존 ID는 고정합니다.
- 모듈 적용: 선택 모듈을 적용/제외/검토 필요로 변경합니다. 검토 필요가 남으면 계산을 막습니다.
- 변경·분석 이력: 수정사유, 시각, 입력 스냅샷, 분석 요약. 선택 시점으로 입력 복원이 가능합니다.

## 엑셀을 기준으로 일정 다듬기

권장: [공통 243개 WBS] → 모듈/날짜 검토 → [입력·결과 엑셀 내보내기] → Excel에서 수정 → [엑셀 가져오기].

지원하는 원본: 동봉한 common_Rev1.xlsx와 이 앱에서 내보낸 교환용 XLSX. 임의 양식의 자동 열 매핑은 아직 지원하지 않습니다.

교환용 시트:
- 프로젝트: PJ_ID / 프로젝트명 / 시작일 / 기준일 / 목표일
- 모듈: 적용/제외/검토 필요
- 작업목록: Activity ID, 모듈, 작업명, 상태, 담당, 산출물, 기간단위, O/M/P, 선행 ID, 잔여 O/M/P, 실제 날짜, 착수 제한일, 기준 일정, 비고
- 휴일: 수동 지정한 휴일 날짜
- 사용안내
- 분석요약 / 작업결과: 분석을 완료한 경우 추가. 결과는 스냅샷이며 엑셀에서 자동 재계산되지 않습니다.

열 순서 변경과 행 추가/정렬은 가능하지만 열 이름은 유지해야 합니다. 선행 ID는 쉼표 또는 세미콜론으로 구분합니다. 입력 기간은 수식 대신 숫자로 기록하세요. 미확정 기간의 빈칸을 0으로 바꾸지 않습니다.

가져오기는 현재 프로젝트를 교체하며, 교체 전 상태를 로컬 이력에 저장합니다. 여러 엑셀을 하나로 병합하지 않습니다. 내보내기는 원본을 재현하는 기능이 아니라 프로그램용 교환 양식을 생성합니다. 기존 문서대장/리스크대장 등 부가 시트는 원본에서 계속 관리하세요.

## 계산 정의

- 독립 삼각분포(O 최소, M 최빈, P 최대), 기간은 표본 추출 후 올림합니다.
- FS+0 관계, 0일 마일스톤 지원. 인력 가용량, Velocity/Tracks, SS/FF, Lag는 미지원입니다.
- 계획: 선행 완료 / 분석 기준 / 착수 제한 중 가장 늦은 날부터 시작.
- 진행: 실제 시작 고정, 기준일 이후 잔여 O/M/P 적용. 선행 완료와 실제 착수가 충돌하면 차단.
- 완료: 실제 시작·완료 고정. 프로젝트 시작일은 해당 실제 날짜를 포함하는 사업 시작일로 입력하세요.
- 보류: 계산 차단. 제외: 기간 0이며 선행 연결 유지.
- 달력일: 날짜 차이 기준. 10/1 착수, 1일 기간은 10/2 완료.
- 근무일: 월~금, 휴일 시트 제외. 0일 작업은 이동하지 않습니다. 비근무일 착수의 양수 기간 작업은 다음 근무일로 이동합니다.
- 예: 금요일 착수 1근무일 작업은 다음 월요일 완료이며, 월요일이 등록 휴일이면 화요일 완료입니다.
- 국가 공휴일은 자동 갱신하지 않습니다.
- 목표 확률: 프로젝트의 모든 작업이 목표 날짜까지 완료된 반복의 비율.
- 분위수: numpy quantile의 higher 방식. 동일 입력/반복/Seed/엔진 및 라이브러리 버전에서 재현합니다.
- 기관 간 지연 상관관계, 자원 경합, 실적 기반 자동 학습은 아직 반영하지 않습니다.
- 동봉 템플릿의 기간은 미보정 가정값입니다. 프로젝트에 적용하기 전에 검토하세요.

## 이력과 백업

저장 위치: `%LOCALAPPDATA%\ProjectScheduleLab\history.sqlite3` (Windows).
수정 시마다 입력 전체를 보관하므로 복원이 가능합니다. 기준선 저장은 이름을 붙인 독립 스냅샷이며 승인 워크플로는 아닙니다. 기준 시작/완료 열은 별도의 수동 입력값입니다.
분석 시 현재 입력, 완료일 요약, 반복 횟수, Seed, 엔진 버전을 저장합니다. 모든 반복의 원시 배열은 DB에 저장하지 않습니다.
화면에는 최근 300건을 표시하며 DB에는 전체 이벤트가 남습니다. 프로그램 종료 후 DB 파일을 복사해 백업하세요. 엑셀에는 현재 입력/결과만 있고 전체 수정이력은 들어가지 않습니다.
단일 사용자 로컬 사용을 전제로 합니다. 공유폴더 DB 동시 편집은 지원하지 않습니다.

## 검증 범위

자동 검증: 직렬/병렬 일정, 제외 처리, 누락/순환 선행 ID, 실제·잔여 일정, 주말·휴일, 0일 마일스톤, 고정 Seed 재현성, SQLite 기록·복원, 공통 243개 작업 5,000회 계산, 엑셀 내보내기 후 재가져오기 입력 일치. `python test_core.py`로 실행합니다.
Python 구문 검증 완료. 제작 환경에 그래픽 디스플레이가 없어 실제 창의 시각 검증 및 Windows GUI 클릭 시험은 수행하지 못했습니다. 초안 검토 시 화면 배율·폰트·배치와 파일 대화상자도 확인해 주세요.

## 문제 해결

- py/python 미인식: Python 설치 후 새 터미널에서 재실행합니다.
- pip 미인식: install.bat은 python -m pip 형식을 사용합니다.
- Tcl/Tk 오류: Windows Python 설치 관리에서 Tcl/Tk를 추가합니다.
- PermissionError: Excel에서 대상 파일을 닫고 다른 파일명으로 저장합니다.
- 초기 기간 미입력: 해당 작업을 편집하거나 Excel 숫자 값을 입력합니다.
- 검토 필요 모듈: 실제 적용성을 결정한 후 계산합니다.
- 오류 종료: 실행 터미널 메시지 또는 `%LOCALAPPDATA%\ProjectScheduleLab\error.log`를 확인합니다.
