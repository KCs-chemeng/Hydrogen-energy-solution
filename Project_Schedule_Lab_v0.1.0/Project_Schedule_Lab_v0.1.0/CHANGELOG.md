# 0.2.2

- Import 미리보기에서 적용 버튼이 창 아래로 밀려 보이지 않는 문제 수정. 상단 고정 액션과 스크롤 가능한 미리보기 적용.
- 가져올 프로젝트·작업 수·아직 적용 전 상태·완료 메시지를 명시하고 적용 후 작업목록으로 전환합니다.
- 다른 프로젝트 파일은 별도 신규 프로젝트 미리보기로 바로 열며 기존 입력을 보존합니다. 오류 차단·충돌 선택·트랜잭션은 유지합니다.
- 프로젝트 전환 시 이전 작업 검색어를 지워 새 업무가 숨겨지지 않도록 합니다.

# 0.2.0

- v1 이벤트 스냅샷을 보존하는 schema v2 이전·자동 사전 백업 및 실패 롤백.
- 프로젝트별 UID/버전·작업 UID, 프로젝트 복제 관계 매핑, 필드별 전후/변경자/사유/경로 이력.
- SQLite 프로젝트/작업/관계/달력/모듈/승인 기준 일정/예측/Import 실행 기록 분리.
- PSL-2 엑셀 비교 미리보기, 선택 적용, 빈 셀 보존·명시적 지우기, 누락 보존, 3방향 충돌 검토.
- 여러 관계·달력·추가 근무일·메타데이터·조회용 기준 일정 버전 Export. 기존 Rev1/PSL-0.1 입력 유지.
- 공통 벡터화 FS/SS/FF·시차 엔진으로 M 계산과 몬테카를로 연결, 고정 날짜 충돌·보류 미확정 차단.
- 실적 보존·위반 경고·진행 잔여 FS 게이트, 목표일 차이/임계 작업/달력일 총 여유 구분.
- 제외 관계의 자동 0일 재연결을 제거하고 영향 검토·계산 차단으로 변경. 이는 명시적인 안전 정책 변경이며 원 관계는 이력에 보존.
- 기존 GUI 보완: 프로젝트 메뉴, 관계·달력·모듈 편집, 예측/오류/여유 결과, 기준 일정 조회, 백업/복원.
- 검증용 엑셀·자동 테스트·실행 스크립트·이전/검수 안내·원본 Import 보고서 추가.

미구현·플랫폼 검증 제한은 README_KO.md에 명시했습니다. 원본 참고 엑셀의 누락 날짜와 적용성은 자동 보정하지 않았습니다.
