# Hydrogen-energy-solution

Python/Tkinter 기반 단일 사용자 프로젝트 일정·업무 이력관리 도구입니다. 현재 프로그램·계산 엔진 버전은 **0.2.0**이며 기존 소스 디렉터리 이름은 유지했습니다.

- [설치·실행·데이터 이전·검수 안내](Project_Schedule_Lab_v0.1.0/Project_Schedule_Lab_v0.1.0/README_KO.md)
- [변경사항](Project_Schedule_Lab_v0.1.0/Project_Schedule_Lab_v0.1.0/CHANGELOG.md)
- [검증 결과](Project_Schedule_Lab_v0.1.0/Project_Schedule_Lab_v0.1.0/reports/validation.md)
- [원본 엑셀 사전 검토](Project_Schedule_Lab_v0.1.0/Project_Schedule_Lab_v0.1.0/reports/reference_import_report.md)

프로그램 폴더에서 Windows는 `install.bat` → `start.bat`, Linux/macOS는 `bash install.sh` → `bash start.sh`로 실행합니다. Python과 Tcl/Tk가 필요합니다. 표준 템플릿·수작업 검증 엑셀은 `examples/`에 있습니다. `python build_release.py`로 전체 소스·문서·예제·실행 스크립트 ZIP을 만듭니다.
