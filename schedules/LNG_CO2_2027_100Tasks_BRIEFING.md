## 1. 관리 단위 재작성

세부 문서 요청·회신·검측·검사 준비를 하나씩 나열하던 구조를 공정상 관리해야 하는 성과물과 Gate로 집계했습니다. 일정표 내부에 `구433_신100_대응`을 넣어 기존 433개 업무의 범위가 어디에 집계·재배치됐는지 추적할 수 있습니다. 공통 CO2 업무를 세 Package로 나누거나 공통 VP 검토를 Package별 승인으로 분산한 다대다 대응도 있습니다. 이 표는 범위 추적표이며 모든 구 공정/기간의 일대일 동치 또는 승인 이력 이전을 뜻하지 않습니다.

분야별 구성: 착수·부지 5, 공정·레이아웃·허가도서 7, 인허가·안전 9, 상세설계 5, Package 조달 45, 토건·설치 11, 현장 연결 5, 검사·시운전·인수 13 = **100개**.

## 2. 레이아웃 → 건축허가용 도서 → 상세설계

- B06 레이아웃 동결 → **B07 건축허가용 도서** → D01~D05 상세 도서.
- 건축허가용 예비 GA·하중·배치와 시공용 최종 Vendor 하중·앵커·노즐·전력 데이터를 구분합니다.
- B07과 행정 선행조건을 갖추면 C02 건축허가 심사를 진행합니다. 상세 설계 전체의 완료를 허가 신청 선행으로 걸지 않았습니다.
- 상세설계는 허가 심사와 병행할 수 있습니다. 허가 취득·착공조건 확인과 최종 IFC 확보는 C09/E01의 토건 착수에 반영합니다.
- 검사·사용승인·환경/안전·운영조건은 G07 가스 도입 전 Gate로 유지했습니다.

## 3. Skid·발주 Package별 관리

| 코드 | Package | 포함/인터페이스 가정 |
|---|---|---|
| P01 | LNG 저장·기화 | 저장탱크·기화기·부속 공급 범위 |
| P02 | 원료가스 조압·계량·차단 Skid | 공급자 분계점~개질기 전단 |
| P03 | 개질·수소정제 Skid | 개질·정제 기능별 경계·제품 조건 |
| P04 | 수소 압축·버퍼 | 압축기 Skid 및 버퍼용기 |
| P05 | CO2 포집·재생 Skid | 흡수·재생·열원·흡수제 경계 |
| P06 | CO2 압축·액화 Skid | 압축·냉동·액화·저온 인터페이스 |
| P07 | CO2 저장·출하 | 탱크·출하·인수 조건 |
| P08 | 공통 유틸리티 Skid | IA·냉각·순수·질소 |
| P09 | 전기·제어·분석 | MCC·PLC·제어반·분석/샘플링 Panel |

각 Package의 관리 단계는 **01 RFQ·기술평가·발주 → 02 Vendor 자료 → 03 제작도·ITP 승인 → 04 제작·조립 → 05 FAT·Punch·출하·현장 인수**입니다. 같은 레이아웃/사양 기준을 공유하고 발주와 제작은 Package별로 병행합니다. 각 설치 E03~E11은 자기 Package 입고와 작업면 인계가 완료되면 착수하도록 했습니다.

탱크·압력용기·전기반을 모두 물리적 Skid라고 단정하지 않았습니다. 이 표는 발주/인터페이스 관리용 경계이며 최종 공급업체·계약 범위에 따라 분할/통합해야 합니다. 기존 계산 범위였던 현장 LNG 저장·기화는 유지했습니다.

F01 외부배관/Tie-in과 F02 현장 배선은 설치와 병행하도록 SS를, 최종 Skid 연결·마감이 설치보다 먼저 끝나지 않도록 FF를 사용했습니다. SS+2/3일 및 FF+3/5일은 명시적인 계획 가정이며 실제 작업면과 팀 확보 조건으로 재확정해야 합니다. 자원 평준화는 하지 않습니다.

## 4. 기간과 예측 결과

단순히 433개 기간을 100개에 직렬 합산하거나 비율 축소하지 않았습니다. 집계 성과물의 O/M/P, Package 납기, 현장 범위와 선행조건을 다시 설정했습니다. 모든 값은 **달력일 계획 가정**이며 견적·허가 일정·작업면을 확인한 확정 납기가 아닙니다. 개별 기간을 집계한 삼각분포는 기존 세부 독립분포의 합과 통계적으로 동일하지 않습니다.

동일한 2027-01-01 시작, 5,000회, Seed 42 기준:

| 예측 | 기존 433개 | R2 100개 |
|---|---|---|
| 최빈 M 기준 | 2028-01-08 | **2028-03-25** |
| P50 | 2028-04-12 | **2028-05-31** |
| P80 | 2028-04-22 | **2028-06-17** |
| P90 | 2028-04-28 | **2028-06-26** |

**업무 수 감소가 공기 단축을 뜻하지 않습니다.** 재작성한 기간·의존관계에서는 P80이 기존보다 56일 늦게 나옵니다. 주요 제약은 CO2 Vendor 자료 → 상세 공정·제어 도서 → 해당 안전심사 → 토건 착공·건축/작업면 → 현장 전계장·검사 → 시운전입니다. 예측을 목표일에 억지로 맞추지 않았으며 이 숫자를 승인 기준 일정으로 저장하지 않았습니다.

## 5. 검증과 사용

- Import 오류·경고 0건, SQLite 저장·재읽기·기존 프로젝트 보존·수정 없는 재Import 무변경 확인.
- 신규 데이터 테스트 9개 통과: 허가도서 선행, 상세설계/심사 병행 경로, 9개 Package 단계/독립 설치, 모든 표본의 FS/SS/FF 제약, 가스 투입 Gate, O=M=P 엔진 일치, 433개 범위 대응.
- 실제 Tk GUI에서 기존 433개 프로젝트를 유지한 채 R2 100개를 신규 Import하고, 5,000회 계산 및 P95 로드맵 100개 막대·249개 연결선까지 확인했습니다.
- 작성자·담당자 개인명, 원본 참고·실적 자료는 포함하지 않습니다. 새로운 설명은 일반 공정·발주관리 가정입니다.
- Windows 화면 배율/폰트/수동 파일 대화상자 시험은 수행하지 않았습니다. 앱 코드는 변경하지 않았고 기존 v0.2.2를 사용합니다.

**v0.2.2 앱 → 엑셀 가져오기 → 상단 ‘선택한 변경 적용’ → 프로젝트 `LNG-CC-202701-R2-100`, 업무 100개 확인 → 시뮬레이션**.

R2는 별도 프로젝트 UID/ID를 사용합니다. 기존 433개 프로젝트를 삭제·덮어쓰지 마세요. Excel의 참고 시트(변경요약·작성가정·Package 범위·구신대응)는 앱 재Export에서 복제되지 않으므로 배포 원본을 보관하세요.
